# CubeMaster — магазин кубиков Рубика

## Описание

Учебный проект по дисциплине «Фронтенд и бэкенд разработка».
Тема контрольной работы №1: «HTML и CSS: разработка многостраничного сайта».
Интернет-магазин кубиков Рубика и аксессуаров для спидкубинга, выполненный на чистых HTML и CSS без фреймворков.

## Структура проекта

- `index.html` — главная страница (баннер, популярные товары, преимущества, о нас);
- `catalog.html` — каталог кубиков с фильтрами;
- `product.html` — карточка товара с характеристиками и таблицей сравнения (товар выбирается параметром `?id=` в ссылке);
- `order.html` — страница оформления заявки;
- `contacts.html` — контакты и форма обратной связи;
- `css/style.css` — внешний файл стилей;
- `js/main.js` — минимальный скрипт модального окна;
- `js/product.js` — подстановка данных выбранного товара на странице `product.html`;
- `images/` — изображения товаров (SVG);
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## Используемые технологии

- HTML5;
- CSS3 (без фреймворков);
- Git / GitHub / GitHub Pages;
- JavaScript — модальное окно заявки и отображение выбранного товара на странице карточки.

## Реализованные требования

- многостраничная структура: 5 связанных страниц;
- семантическая разметка: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`;
- единая навигация между страницами на всех страницах;
- якорные ссылки: `#about`, `#catalog`, `#advantages`, `#contacts`;
- карточки товаров с изображениями, бейджами и кнопками действий;
- таблица характеристик и таблица сравнения товаров;
- формы: оформление заказа, обратная связь, фильтры каталога;
- модальное окно оформления заявки (`<dialog>`);
- внешний CSS-файл с CSS-переменными в `:root`;
- состояния элементов `:hover` и `:focus-visible`;
- Flexbox: навигация, кнопки, карточки товаров;
- CSS Grid: сетка товаров, раскладка каталога и преимуществ;
- БЭМ-именование: `product-card`, `product-card__img`, `product-card__title`, `site-nav`, `order-form` и др.;
- позиционирование: sticky-шапка, абсолютные бейджи на карточках;
- адаптивная вёрстка (медиазапросы для планшета и телефона).
